## 多维预测规范（硬性：每个维度必须给出可打分量化口径，一律"中心值 + 窄区间"）

| 维度 | 预测形式（必须写出） | 打分口径（次日评判用） |
|---|---|---|
| 方向 | 主方向 + 中心涨跌幅 μ（%）±0.15 + 置信度 X% | 中心误差 e=\|r−μ\|：同号 e≤0.15→1.0 / ≤0.30→0.85 / ≤0.60→0.60 / ≤1.0→0.30 / >1.0→0.10；异号 0.25/0.10/0.03 |
| 点位 | 上证收盘中心 μ（整数点）+ 窄区间 [μ−5, μ+5]（宽10点，换算涨跌幅与昨收对齐） | 中心误差 d≤5→1.0 / ≤10→0.90 / ≤15→0.75 / ≤20→0.60 / ≤30→0.40 / ≤50→0.20 / >50→0.05 |
| 量能 | 两市成交额中心 T（万亿）±0.1 | e≤0.1→1.0 / ≤0.2→0.85 / ≤0.35→0.60 / ≤0.5→0.35 / >0.5→0.10 |
| 风格 | 成长/价值/均衡 + 强弱描述 | 按成长强度 g=创业板Δ−上证Δ 分档连续 |
| 板块 | 领涨/领跌候选 Top3（含理由，须结合上一交易日板块动量） | 命中榜位 1.00/0.90/0.70/0.45/0.10/0.00 加权；反向命中 0 |
| 资金 | 主力净流入中心 F（亿，可带 ±100 亿） | 同向量级兑现 1.00/0.75/0.45；反向 0.30/0.12/0.03 |
| 触发条件 | 情景概率（合计 100%）+ 关键触发事件 | 按实际兑现情景的报出概率 p 计分：p≥60%→1.0 / 40-60%→0.75 / 20-40%→0.50 / <20%→0.25 / 相反情景→0.10 |
| 港股 | 恒指中心 μ（点）±50（或涨跌幅中心 ±0.2pct） | 中心误差 d≤50→1.0 / ≤100→0.85 / ≤200→0.65 / ≤350→0.40 / ≤500→0.20 / >500→0.05；只给方向不给中心值上限 0.6 |

权重：方向 25% / 点位 15% / 量能 10% / 风格 10% / 板块 10% / 资金 10% / 触发条件 10% / 风险 5% / 港股 5%（合计 100%）；某维度"未预测"计 0 分并注明。

**窄区间硬性**：任何数值维度必须写出"中心值"；给不出中心值时按低置信处理（上限 0.6 并注明"未给中心值"）。禁止用"接近 X"等无中心表述。

## 打分补充规则（评判昨日时执行）

- 每维度得分 ∈ [0.00, 1.00]，步长 0.01；总分 = Σ(维度分 × 权重)；
- 方向对了但幅度差很远不得高分（如预测 +0.3% 实际 +1.0% → 0.30 分）；
- 打分以上一交易日实际收盘数据对照（在下一份晨报底稿中体现）；本份晨报只需按规则给昨日打分，数据缺失的维度标注"未获取（不计入总分）"。

# 多维评判·精细连续评分规则 v3（完整存档）

> 来源：本地链路 prompts/multi-dim-scoring-v3-prompt.md（2026-09-08 打包迁移）。
> 云端晨报 am.md 已内嵌浓缩版；本文件为完整规则，供人工评分、周度统计或后续脚本化打分（ledger）使用。

## 〇、通用规则

1. 每维度得分 ∈ [0.00, 1.00]，步长 0.01；
2. 数值维度一律用"中心误差"计分：`e = |实际值 − 预测中心|`，误差落在窄区间内 = 1.00，区间外按误差分段线性衰减；
3. 中心与半宽以晨报预测原文为准：点位中心 μ（整数点）、半宽 5 点；涨跌幅中心 μ、半宽 0.15pct；量能中心 T、半宽 0.1 万亿；恒指中心、半宽 50 点；
4. 未预测维度计 0 分并注明"未预测"；禁止事后把区间改宽补命中；
5. 总分 = Σ(维度分 × 权重)；评级：≥0.90 优秀 / 0.75-0.89 良好 / 0.60-0.74 合格 / 0.40-0.59 一般 / <0.40 差；
6. 权重：方向 25% / 点位 15% / 量能 10% / 风格 10% / 板块 10% / 资金 10% / 触发 10% / 风险 5% / 港股 5%。

## 一、方向-幅度维度（25%）：按"中心涨跌幅兑现比例"计分，方向对≠高分

预测给主方向 + 中心涨跌幅 μ（%）+ 置信度。实际以上证收盘涨跌幅 r 对照，e = |r − μ|（pct）。

**同号**：e≤0.15→1.00；0.15<e≤0.30→0.85；0.30<e≤0.60→0.60；0.60<e≤1.00→0.30；e>1.00→0.10。
**异号**：|r|≤0.30→0.25；0.30<|r|≤0.80→0.10；|r|>0.80→0.03。

## 二、点位维度（15%）：按收盘偏离预测中心的点数计分

预测给上证收盘中心 μ + 窄区间 [μ−5, μ+5]。d = |C − μ|：
d≤5→1.00；5<d≤10→0.90；10<d≤15→0.75；15<d≤20→0.60；20<d≤30→0.40；30<d≤50→0.20；d>50→0.05。

## 三、量能维度（10%）

预测给两市成交额中心 T（万亿）+ 区间 ±0.1。e=|A−T|：
e≤0.1→1.00；0.1<e≤0.2→0.85；0.2<e≤0.35→0.60；0.35<e≤0.5→0.35；e>0.5→0.10。

## 四、风格维度（10%）：按成长强度 g = 创业板Δ − 上证Δ 兑现程度计分

- 成长：g≥+0.3%→1.00；+0.1~0.3%→0.90；0~+0.1%→0.75；−0.2~0→0.55；−0.5~−0.2%→0.30；<−0.5%→0.10；
- 价值：g≤−0.3%→1.00；−0.3~−0.1%→0.90；−0.1~0→0.75；0~+0.2%→0.55；+0.2~+0.5%→0.30；>+0.5%→0.10；
- 均衡：|g|≤0.3%→1.00；0.3-0.6%→0.70；0.6-1.0%→0.45；>1.0%→0.20。

## 五、板块维度（10%）：候选命中榜位加权

第1→1.00；第2-3→0.90；第4-5→0.70；未上榜同向（±0.5%内）→0.45；未上榜反向→0.10；反向命中→0.00；最终=各候选平均。

## 六、资金维度（10%）：方向一致 + 量级兑现比例

同向且|A|≥0.5|F|→1.00；同向 0.2|F|≤|A|<0.5|F|→0.75；同向严重不足或超 3 倍→0.45；反向轻微（≤50亿）→0.30；反向中等（50-200亿）→0.12；反向严重（>200亿）→0.03。

## 七、触发维度（10%）：按实际兑现情景的报出概率 p 计分

p≥60%→1.00；40-60%→0.75；20-40%→0.50；<20%→0.25；相邻档未完全兑现→最高档分−0.15（下限0.3）；兑现相反情景→0.10。

## 八、风险维度（5%）：预警覆盖度

发生且命中核心词→1.00；发生但部分预警→0.70；发生但未预警→0.20；未发生且未过度预警→0.95；未发生但连续≥3日未兑现→0.60。

## 九、港股维度（5%）

恒指中心误差 d≤50→1.00；50<d≤100→0.85；100<d≤200→0.65；200<d≤350→0.40；350<d≤500→0.20；d>500→0.05；只给方向不给中心值上限 0.6。

## 十、输出格式

每维度输出：`维度 | 昨日预测原文(中心+区间) | 实际 | 误差 e/d | 得分(0.01) | 说明`；总分与评级按通用规则。
